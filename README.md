# Fahrizal & Salsa

Halaman web kenangan interaktif untuk anniversary Fahrizal & Salsa (jadian 29 November 2025).

## Isi

- `fahrizal-salsa.html` — halaman single-file (HTML/CSS/JS + Three.js) dengan efek scroll-driven
  animation. Latar galaksi bintang 3D berubah bentuk mengikuti scroll (tersebar → dua bintang →
  mendekat → hati → kilau → infinity → hati penuh), berdampingan dengan timeline perjalanan
  (Pertama Ketemu, Mulai Dekat, Jadian, Momen Berkesan, Sekarang), countdown otomatis ke
  anniversary pertama (29 November 2026), dan surat kecil untuk Salsa.

## Cara pakai

Buka `fahrizal-salsa.html` langsung di browser — tidak perlu build step atau server, semuanya
sudah jadi satu file. Bagian yang ditandai `[ISI DI SINI]` adalah placeholder foto/cerita yang
masih perlu diisi konten aslinya.
